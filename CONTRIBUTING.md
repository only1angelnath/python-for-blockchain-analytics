# Contributing

Contributions are welcome and appreciated. Here's how to help:

## Types of contributions

- **Bug fixes** — broken code, outdated API examples, wrong explanations
- **Better blockchain examples** — if a concept has a clearer on-chain analogy
- **Additional exercises** — more practice problems for any week
- **Translations** — README or lesson translations for other languages
- **New lessons** — proposals for additional topics (open an issue first)

## How to contribute

1. Fork the repository
2. Create a feature branch: `git checkout -b fix/week-08-pandas-typo`
3. Make your changes
4. Commit with a clear message: `git commit -m "fix: corrected groupby example in week-08"`
5. Push and open a Pull Request

## Code style

- Python: follow PEP 8, use meaningful variable names
- Notebooks: clear markdown cells explaining each concept before the code
- Exercise files: include the problem as a comment, solution below a `# Solution:` comment

## Questions

Open an issue or reach out via GitHub Discussions.
