## Who this is for

This course is built for three types of learners — all arriving at the same destination:

| Background | Entry point | What this gives you |
|---|---|---|
| **Complete Python beginner** | Phase 0 — follow everything | Full Python + blockchain data engineering + ML |
| **Blockchain / crypto native** | Phase 0 — you know the domain, learn the tools | Code skills to match your on-chain knowledge |
| **SQL analyst (e.g. Dune)** | Phase 0 — your query thinking is an asset | Python, pipelines, and ML on top of your SQL foundation |

Every concept is taught with a **blockchain-native example**. SQL analysts get explicit parallels throughout (`groupby()` ≈ `GROUP BY`, `merge()` ≈ `JOIN`, etc.).

## Lesson format

Every week contains two files:

- `lesson.ipynb` — Jupyter notebook: concept explanation + runnable code examples
- `exercises.py` — Python file: practice problems with solutions

Capstone projects get their own folder with a full `README.md`, `requirements.txt`, and deployment instructions.

## Phases at a glance

### Phase 0 — Setup (Week 1)
Install Python, VS Code, Jupyter. Learn Git and push your first commit. Non-negotiable foundation.

### Phase 1 — Python Fundamentals (Weeks 2–6)
Syntax, variables, control structures, data structures, functions, OOP. Every concept anchored to a blockchain example. Capstone: build a simulated blockchain in pure Python.

### Phase 2 — Python for Data (Weeks 7–10)
Pandas, NumPy, Matplotlib, APIs (Etherscan, CoinGecko, Dune SIM), SQL from Python. Capstone: multi-source DeFi analytics dashboard.

### Phase 3 — Blockchain Analytics (Weeks 11–14)
Blockchain data structures, web3.py, DEX analysis, Streamlit dashboards. Capstone: deployed wallet analytics app.

### Phase 4 — Advanced Python (Weeks 15–19)
Decorators, async/await, pytest, Pydantic, packaging. Capstone: pip-installable blockchain SDK.

### Phase 5 — Data Engineering (Weeks 20–25)
ETL pipelines, dbt, Apache Airflow, Kafka streaming, Docker, CI/CD. Capstone: production DeFi data pipeline.

### Phase 6 — System Design (Weeks 26–29)
Scalability, caching, microservices, reliability patterns, IaC. Capstone: architecture document for a multi-chain analytics platform.

### Phase 7 — ML Engineering (Weeks 30–35)
Math foundations, supervised + unsupervised learning, deep learning (LSTM, Transformers), MLOps. Capstone: deployed ML models for wallet clustering, anomaly detection, and risk scoring.

### Final Capstone — ChainLens (Week 36)
A full-stack blockchain intelligence platform combining every phase into one production-grade system.

## How to follow this course

1. **Fork this repo** → click the Fork button top-right
2. **Clone your fork** locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/python-for-blockchain-analytics.git
   cd python-for-blockchain-analytics
   ```
3. **Start at Phase 0** — follow the README in each phase folder
4. **Commit your work** at least once per week:
   ```bash
   git add .
   git commit -m "phase-1/week-02: completed syntax exercises"
   git push
   ```
5. **Build in public** — post your progress on Twitter/X or LinkedIn weekly
