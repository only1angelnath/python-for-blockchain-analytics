# Course Roadmap — Week by Week

Full curriculum breakdown. Each phase links to its folder README for detailed lesson plans.

---

## Phase 0 — Setup (Week 1)
- [ ] Dev environment: Python 3.12+, VS Code, Jupyter Lab
- [ ] Git + GitHub: init, add, commit, push, branching
- [ ] Milestone: fork repo, push first commit

## Phase 1 — Python Fundamentals (Weeks 2–6)
- [ ] Week 2: Syntax, variables, data types
- [ ] Week 3: Control structures — loops and conditionals
- [ ] Week 4: Data structures — lists, dicts, tuples, sets
- [ ] Week 5: Functions and modules
- [ ] Week 6: Object-oriented programming (OOP)
- [ ] Capstone: `simple-chain` — simulated blockchain in pure Python

## Phase 2 — Python for Data (Weeks 7–10)
- [ ] Week 7: File handling (CSV, JSON) + error handling
- [ ] Week 8: Pandas + NumPy
- [ ] Week 9: Data visualization (Matplotlib, Seaborn, Plotly)
- [ ] Week 10: APIs (Etherscan, CoinGecko, Dune SIM) + SQL from Python
- [ ] Capstone: `defi-dashboard` — local multi-source analytics dashboard

## Phase 3 — Blockchain Analytics (Weeks 11–14)
- [ ] Week 11: Blockchain data structures (blocks, txns, logs, ABIs)
- [ ] Week 12: web3.py — reading on-chain data
- [ ] Week 13: DEX + DeFi analysis (Uniswap, NFTs, MEV)
- [ ] Week 14: Streamlit dashboards — deployed analytics app
- [ ] Capstone: `chain-analyst` — deployed wallet analytics app

## Phase 4 — Advanced Python (Weeks 15–19)
- [ ] Week 15: Functional Python (comprehensions, generators, iterators)
- [ ] Week 16: Decorators + context managers
- [ ] Week 17: Async Python + concurrency (asyncio, aiohttp)
- [ ] Week 18: Testing (pytest) + static typing (Pydantic, mypy)
- [ ] Week 19: Packaging + tooling (Poetry, pyproject.toml, PyPI)
- [ ] Capstone: `blockchain-sdk` — pip-installable Python SDK

## Phase 5 — Data Engineering (Weeks 20–25)
- [ ] Week 20: Data modelling + warehousing (star schema, OLAP, PostgreSQL)
- [ ] Week 21: ETL pipelines + dbt
- [ ] Week 22: Orchestration with Apache Airflow
- [ ] Week 23: Streaming with Kafka + WebSockets
- [ ] Week 24: Docker + CI/CD (GitHub Actions)
- [ ] Week 25: Data quality + governance
- [ ] Capstone: `defi-pipeline` — production DeFi data stack

## Phase 6 — System Design (Weeks 26–29)
- [ ] Week 26: Scalability, latency, CAP theorem
- [ ] Week 27: Databases + caching (sharding, Redis)
- [ ] Week 28: Microservices + messaging (Kafka, gRPC, REST)
- [ ] Week 29: Reliability patterns + IaC (Terraform, circuit breaker)
- [ ] Capstone: Architecture document for a multi-chain analytics platform

## Phase 7 — ML Engineering (Weeks 30–35)
- [ ] Week 30: Math foundations (linear algebra, statistics, probability)
- [ ] Week 31: Data preparation for ML (feature engineering, scaling)
- [ ] Week 32: Supervised learning (regression, random forest, XGBoost)
- [ ] Week 33: Unsupervised learning (clustering, anomaly detection)
- [ ] Week 34: Deep learning (PyTorch, LSTM, Transformers)
- [ ] Week 35: MLOps + model deployment (MLflow, FastAPI serving)
- [ ] Capstone: `defi-ml` — deployed ML model suite

## Final Capstone — ChainLens (Week 36)
- [ ] Full-stack blockchain intelligence platform
- [ ] All phases integrated: SDK → pipeline → ML → API → dashboard
- [ ] Deployed: Railway (backend) + Vercel (frontend)
- [ ] Deliverables: live demo, architecture doc, demo video, blog post
