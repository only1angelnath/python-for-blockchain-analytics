# Final Capstone — ChainLens

**Duration:** Week 36 | **~20 hours**

A full-stack blockchain intelligence platform combining every phase into one production-grade system.

## What it does
- Ingests live data from Ethereum, Base, and Arbitrum
- ETL pipeline: Airflow + dbt → PostgreSQL warehouse
- Three ML models: wallet clustering, anomaly detection, liquidation risk
- FastAPI serving analytics + ML predictions
- Next.js + Recharts frontend dashboard
- Fully Dockerized, CI/CD on GitHub Actions
- Deployed: Railway (backend) + Vercel (frontend)
