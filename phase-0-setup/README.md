# Phase 0 — Setup

**Duration:** Week 1 | **~6 hours**

Before writing a single line of Python, every learner sets up their machine, learns Git, and pushes their first commit.

## What you'll set up
- Python 3.12+ installed and working
- VS Code with Python + Jupyter extensions
- Jupyter Lab running locally
- Git configured with your GitHub account

## Lessons
1. [Environment Setup](01-environment-setup.md)
2. [Git + GitHub Workflow](02-git-github-workflow.md)

## Milestone
Your repo is forked, your environment works, and your first commit is pushed. Post it.
