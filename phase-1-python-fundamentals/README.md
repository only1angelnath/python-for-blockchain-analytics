# Phase 1 — Python Fundamentals

**Duration:** Weeks 2–6 | **~40 hours**

Zero to functional Python. Every concept taught with a blockchain example. SQL analysts get explicit parallels throughout.

## Self-assessment (can you skip?)
Answer these before starting. If you can answer all confidently, review quickly and move to Phase 2.
- What is the difference between a list and a tuple?
- Write a function that takes a wallet address and returns whether it starts with `0x`.
- What is a dictionary? How would you use one to store token balances?
- Write a class `Wallet` with a `deposit()` method.
