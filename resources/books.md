# Recommended Reading

Curated books and free resources per phase. 🆓 = completely free online.

---

## Phase 1 — Python Fundamentals

- 🆓 [Official Python Tutorial](https://docs.python.org/3/tutorial/) — start here
- 🆓 [Automate the Boring Stuff with Python](https://automatetheboringstuff.com/) — practical, project-based intro
- 🆓 [Python Cheatsheet](https://www.pythoncheatsheet.org/) — quick reference for syntax

---

## Phase 2 — Python for Data

- 🆓 [Python for Data Analysis (3rd ed.)](https://wesmckinney.com/book/) — Pandas creator's book, free online
- 🆓 [Pandas documentation](https://pandas.pydata.org/docs/) — official, excellent user guide
- 🆓 [NumPy documentation](https://numpy.org/doc/stable/user/index.html) — official user guide

---

## Phase 3 — Blockchain Analytics

- 🆓 [web3.py documentation](https://web3py.readthedocs.io/) — official reference
- 🆓 [Ethereum Yellow Paper](https://ethereum.github.io/yellowpaper/paper.pdf) — deep protocol reference
- 🆓 [Mastering Ethereum (free on GitHub)](https://github.com/ethereumbook/ethereumbook) — comprehensive EVM book
- 🆓 [DefiLlama API docs](https://defillama.com/docs/api) — TVL and protocol data reference
- 🆓 [The Graph documentation](https://thegraph.com/docs/) — subgraph queries
- 🆓 [Envio documentation](https://docs.envio.dev/) — HyperIndex indexer

---

## Phase 4 — Advanced Python

- 🆓 [Fluent Python (2nd ed.)](https://www.oreilly.com/library/view/fluent-python-2nd/9781492056348/) — advanced Python patterns
- 🆓 [Python Testing with pytest](https://pragprog.com/titles/bopytest2/python-testing-with-pytest-second-edition/) — testing best practices
- 🆓 [Real Python — decorators](https://realpython.com/primer-on-python-decorators/) — free article, excellent depth
- 🆓 [asyncio documentation](https://docs.python.org/3/library/asyncio.html) — official async reference

---

## Phase 5 — Data Engineering

- 🆓 [Fundamentals of Data Engineering](https://www.oreilly.com/library/view/fundamentals-of-data/9781098108298/) — Joe Reis and Matt Housley
- 🆓 [dbt documentation](https://docs.getdbt.com/) — official, comprehensive
- 🆓 [Apache Airflow documentation](https://airflow.apache.org/docs/) — official reference
- 🆓 [Kafka documentation](https://kafka.apache.org/documentation/) — official reference
- 🆓 [Envio / HyperIndex docs](https://docs.envio.dev/docs/HyperIndex/overview) — fast indexing

---

## Phase 6 — System Design

- 🆓 [System Design Primer (GitHub)](https://github.com/donnemartin/system-design-primer) — free, comprehensive, 250k stars
- 🆓 [ByteByteGo Newsletter](https://blog.bytebytego.com/) — free tier covers most system design patterns
- [Designing Data-Intensive Applications](https://dataintensive.net/) — Martin Kleppmann — the definitive book

---

## Phase 7 — ML Engineering

- 🆓 [fast.ai Practical Deep Learning](https://course.fast.ai/) — hands-on, code-first
- 🆓 [scikit-learn documentation](https://scikit-learn.org/stable/user_guide.html) — official user guide
- 🆓 [Hands-On ML with Scikit-Learn, Keras & TensorFlow](https://github.com/ageron/handson-ml3) — code on GitHub
- 🆓 [PyTorch documentation](https://pytorch.org/docs/stable/index.html) — official reference
- 🆓 [MLflow documentation](https://mlflow.org/docs/latest/index.html) — official reference

---

## Blockchain data engineering — specialist reading

- 🆓 [Uniswap V3 Whitepaper](https://uniswap.org/whitepaper-v3.pdf) — concentrated liquidity deep dive
- 🆓 [Ethereum EIPs](https://eips.ethereum.org/) — Ethereum Improvement Proposals (primary source for protocol changes)
- 🆓 [OpenZeppelin Contracts](https://docs.openzeppelin.com/contracts/) — standard ERC implementations with explanations
- 🆓 [MEV Wiki](https://www.mev.wiki/) — comprehensive MEV reference
