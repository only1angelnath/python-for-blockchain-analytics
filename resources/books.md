# Recommended Reading

Curated books and resources per phase. All free resources marked with 🆓.

## Phase 1 — Python Fundamentals
- 🆓 [Official Python Tutorial](https://docs.python.org/3/tutorial/) — start here
- 🆓 [Automate the Boring Stuff with Python](https://automatetheboringstuff.com/) — practical intro

## Phase 2 — Python for Data
- 🆓 [Python for Data Analysis](https://wesmckinney.com/book/) — Pandas creator's book (free online)
- 🆓 [Pandas documentation](https://pandas.pydata.org/docs/) — official, excellent

## Phase 3 — Blockchain Analytics
- 🆓 [web3.py documentation](https://web3py.readthedocs.io/)
- 🆓 [Ethereum Yellow Paper](https://ethereum.github.io/yellowpaper/paper.pdf) — deep reference
- 🆓 [Dune Analytics docs](https://docs.dune.com/)

## Phase 4 — Advanced Python
- 🆓 [Fluent Python (2nd ed.)](https://www.oreilly.com/library/view/fluent-python-2nd/9781492056348/) — advanced patterns
- 🆓 [Python Testing with pytest](https://pragprog.com/titles/bopytest2/python-testing-with-pytest-second-edition/)

## Phase 5 — Data Engineering
- 🆓 [Fundamentals of Data Engineering](https://www.oreilly.com/library/view/fundamentals-of-data/9781098108298/) — Joe Reis
- 🆓 [dbt documentation](https://docs.getdbt.com/)
- 🆓 [Apache Airflow documentation](https://airflow.apache.org/docs/)

## Phase 6 — System Design
- 🆓 [System Design Primer (GitHub)](https://github.com/donnemartin/system-design-primer) — free, comprehensive
- [Designing Data-Intensive Applications](https://dataintensive.net/) — Martin Kleppmann, the definitive book

## Phase 7 — ML Engineering
- 🆓 [fast.ai Practical Deep Learning](https://course.fast.ai/) — hands-on deep learning
- 🆓 [scikit-learn documentation](https://scikit-learn.org/stable/user_guide.html)
- 🆓 [Hands-On ML with Scikit-Learn, Keras & TensorFlow](https://www.oreilly.com/library/view/hands-on-machine-learning/9781492032632/)
