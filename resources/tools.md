## Phase 0–1: Foundations

- 🆓 [Python 3.12+](https://www.python.org/) — language
- 🆓 [VS Code](https://code.visualstudio.com/) — editor (Python + Jupyter extensions)
- 🆓 [Jupyter Lab](https://jupyter.org/) — interactive notebooks
- 🆓 [Git](https://git-scm.com/) + [GitHub](https://github.com/) — version control

## Phase 2: Data Analysis

- 🆓 [Pandas](https://pandas.pydata.org/) — data manipulation
- 🆓 [NumPy](https://numpy.org/) — numerical computing
- 🆓 [Matplotlib](https://matplotlib.org/) + [Seaborn](https://seaborn.pydata.org/) — charts
- 🆓 [Plotly](https://plotly.com/python/) — interactive charts
- 🆓 [python-dotenv](https://pypi.org/project/python-dotenv/) — load `.env` files safely

## Phase 3: Blockchain Analytics

- 🆓 [web3.py](https://web3py.readthedocs.io/) — Ethereum/EVM interaction
- 🆓 [Streamlit](https://streamlit.io/) — rapid dashboard deployment
- 🆓 [Ankr Public RPC](https://www.ankr.com/rpc/) — free multi-chain node access
- ⚡ [Infura](https://infura.io/) — reliable RPC, 100k req/day free
- ⚡ [Alchemy](https://www.alchemy.com/) — enhanced APIs, 300M CU/month free
- ⚡ [Etherscan](https://etherscan.io/apis) — transaction and contract data
- 🆓 [The Graph](https://thegraph.com/) — query Uniswap, Aave, Curve subgraphs
- 🆓 [DefiLlama API](https://defillama.com/docs/api) — TVL, yields, protocol data
- 🆓 [CoinGecko API](https://www.coingecko.com/api/documentation) — prices, OHLCV
- ⚡ [Helius](https://helius.dev) — Solana RPC + enhanced APIs
