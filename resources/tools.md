# Tools & Platforms

Everything used in this course, organised by phase.

## Phase 0–1: Foundations
- [Python 3.12+](https://www.python.org/) — language
- [VS Code](https://code.visualstudio.com/) — editor
- [Jupyter Lab](https://jupyter.org/) — interactive notebooks
- [Git](https://git-scm.com/) + [GitHub](https://github.com/) — version control

## Phase 2: Data
- [Pandas](https://pandas.pydata.org/) — data manipulation
- [NumPy](https://numpy.org/) — numerical computing
- [Matplotlib](https://matplotlib.org/) + [Seaborn](https://seaborn.pydata.org/) — static charts
- [Plotly Dash](https://dash.plotly.com/) — interactive dashboards

## Phase 3: Blockchain
- [web3.py](https://web3py.readthedocs.io/) — Ethereum interaction
- [Streamlit](https://streamlit.io/) — rapid dashboard deployment
- [Alchemy](https://www.alchemy.com/) / [Infura](https://infura.io/) — RPC node access

## Phase 4: Advanced Python
- [pytest](https://pytest.org/) — testing
- [Pydantic](https://docs.pydantic.dev/) — data validation
- [Poetry](https://python-poetry.org/) — dependency management
- [ruff](https://docs.astral.sh/ruff/) + [black](https://black.readthedocs.io/) — formatting

## Phase 5: Data Engineering
- [Apache Airflow](https://airflow.apache.org/) — pipeline orchestration
- [dbt](https://www.getdbt.com/) — SQL transformations
- [Apache Kafka](https://kafka.apache.org/) — streaming
- [Docker](https://www.docker.com/) + [Docker Compose](https://docs.docker.com/compose/) — containers
- [PostgreSQL](https://www.postgresql.org/) — data warehouse
- [Redis](https://redis.io/) — caching
- [Railway](https://railway.app/) — cloud deployment
- [GitHub Actions](https://github.com/features/actions) — CI/CD

## Phase 6: System Design
- [Terraform](https://www.terraform.io/) — infrastructure as code
- [Prometheus](https://prometheus.io/) + [Datadog](https://www.datadoghq.com/) — monitoring

## Phase 7: ML Engineering
- [scikit-learn](https://scikit-learn.org/) — ML algorithms
- [XGBoost](https://xgboost.readthedocs.io/) — gradient boosting
- [PyTorch](https://pytorch.org/) — deep learning
- [MLflow](https://mlflow.org/) — experiment tracking
- [FastAPI](https://fastapi.tiangolo.com/) — model serving
- [SHAP](https://shap.readthedocs.io/) — model explainability
